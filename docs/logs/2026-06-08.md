Gives everything for free: neutral respect ⇒ ×1 ⇒ cohesion *is* familiarity (the **base level**, and a **regression anchor** = today's behavior, à la Phase B steepness=0); high respect lifts the base (leadership's emergent role); a respected stranger (low familiarity) still contributes ~nothing (respect only matters *through* familiarity); high-familiarity + **negative** respect drops cohesion *below* base (the feud — betrayal among intimates is corrosive). **Open fork:** respect floor at 0 (fragmentation) vs allowed negative (active death spiral) — leaning negative so the spiral can bite.
  - **Performance reconciliation — the pairwise grid is the *mental model*; the code never builds it.** Familiarity is ≈uniform *within* a community (everyone co-resided); respect is *concentrated/directional* toward standing ⇒ collapses to a **per-person standing scalar** (reputation-as-scalar, ~n not n²). Community cohesion = `mean familiarity × (1 + k·aggregate standing)` — O(n) aggregates, no matrix. Bonus: *who* betrays matters (a high-standing family hoarding craters the standing that was anchoring cohesion; a marginal one barely dents it). Other cheap tricks noted: store only *salient* relationships as a sparse overlay on a computed baseline; Dunbar cap (O(n·k)); tier by hierarchy level; lazy/periodic recompute (cohesion as cached stock). Key tie-in: the loop runs until **land-bound**, which is *exactly* when surplus appears and disparity becomes affordable (the Phase B insight) — so prosperity delivers the community to the condition that **arms the vicious loop**.

    - **Tipping point requires asymmetry, not a hard switch:** make respect a **stock** that's *slow to build (leadership accrual), fast to lose (famine shock)*.
