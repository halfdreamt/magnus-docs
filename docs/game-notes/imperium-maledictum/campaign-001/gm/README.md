# GM-only material

Ryan (the player) does not read anything in this directory unless the acting
GM explicitly says a file has become player-safe. Nothing here is
password-protected; the boundary is trust, and agents must respect it in the
other direction too: **never quote, summarise, or hint at this directory's
contents in player-facing conversation or documents.**

Spoiler hygiene for agents:

- The `voll-adventures-*` retrieval collections and transcripts are GM-only
  from printed page 15 onward. Pages 3 and 5–14 (primers, hive and wastes
  gazetteer, rumour tables) are player-safe.
- The AdMech GM's Guide is GM-only throughout, especially the Triumvir
  profiles (p54–59) — the Player's Guide versions (p15–17) are the
  player-safe presentations of the same people, and the differences between
  the two are themselves plot.
- When citing sources to Ryan, cite the Player's Guide or core book wherever
  a player-safe equivalent exists.

- [GM-BRIEFING.md](GM-BRIEFING.md) — **start here**: the ten-minute
  handoff, the beat loop, and the reading list for the next session.
- [table-notes.md](table-notes.md) — table mandates and Ryan's style.
- [session-1-investiture.md](session-1-investiture.md) — current prep
  (Session 02 picks up at Part 0 beat 5).
