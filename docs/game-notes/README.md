# Game notes

This directory is the durable home for tabletop campaign records. Keep each
game in its own directory and each campaign beneath that in a zero-padded
numbered directory (`campaign-001`, `campaign-002`, and so on).

Campaign notes should distinguish among:

- established campaign canon;
- GM preparation that has not yet appeared in play;
- player-facing information;
- unanswered questions and possible ideas.

Do not copy private book prose into tracked notes. Summarise rules and setting
material, record a local source route, and consult the ignored corpus for exact
wording when a ruling matters.
